# Keepsake — Responsive Landing Page

**Demo:** https://pankivkhrystyna.github.io/landing-keepsake/
## Опис проєкту

Keepsake — адаптивна односторінкова вебсторінка портфоліо креативної студії. Сторінка містить головний екран, портфоліо робіт, перелік послуг, статистику, клієнтів, відгук, блог і контактну інформацію.

## Технології

- **HTML5** — семантична розмітка, один головний заголовок `<h1>`.
- **CSS3** — стилізація, CSS-змінні в `:root`, Flexbox та CSS Grid.
- **Без JavaScript** — інтерактивність реалізована засобами HTML і CSS.
- **Без фреймворків**.
- **Google Fonts:** Oswald, Open Sans, Dancing Script (`display=swap`).
- **SVG** — іконки та графічні елементи.
- **WebP** — формат зображень.

## Реалізовані рішення

- **Mobile First:** базові стилі для мобільних пристроїв, адаптація через `@media (min-width: 768px)` та `@media (min-width: 1280px)`.
- **Адаптивні відступи:** значення `--gutter` і `--section-gap` змінюються залежно від ширини екрана.
- **Мобільне меню:** реалізоване без JavaScript за допомогою прихованого `checkbox`, `label` та CSS-селектора `:checked`.
- **Фільтрація портфоліо:** радіокнопки та CSS-селектори `:checked` дозволяють фільтрувати картки за категоріями.
- **Ефекти карток:** інформація з'являється при наведенні, а також при клавіатурній навігації через `:focus-visible` і `:focus-within`.
- **Форма підписки:** HTML-валідація, відображення помилок через `:user-invalid`, повідомлення про успішний стан через `:target` і `:has()`.
- **Фіксована шапка:** `position: fixed` для навігації.
- **Кнопка повернення вгору:** фіксоване розташування за допомогою `position: fixed`.
- **Адаптивні сітки:** кількість колонок змінюється залежно від ширини екрана.

## Запуск проєкту

1. Завантажити або клонувати репозиторій.
2. Відкрити файл `index.html` у браузері.
3. Для перегляду опублікованої версії перейти за посиланням Demo.

## Публікація

Проєкт публікується за допомогою **GitHub Pages**.

У налаштуваннях репозиторію потрібно відкрити `Settings → Pages`, вибрати `Deploy from a branch`, гілку `main` і папку `/ (root)`, після чого натиснути `Save`.
